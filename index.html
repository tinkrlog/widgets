How to embed in Notion

1. Host this folder on GitHub Pages (or any static host).
2. In Notion, type /embed and paste the widget URL, e.g. https://yourusername.github.io/tinkrlog-widgets/greeting-clock.html
3. Resize the embed block to the suggested dimensions.
4. Done — works on free Notion plans, survives template duplication.
